With AI assuming more coding responsibilities, the responsibilities of the developer are now:

- Understanding the code
- Ensuring the code works
- Ensuring the code meets the business needs
- Ensuring the code is maintainable

Questions developers need to answer when reviewing AI code:

- What assumptions did the AI make when writing the code?
    - Use the example of the AI using an ORM in my Python code but I did not want to use an ORM.
- For existing code bases, does this new AI generated code integrate well into our existing codebase?
    - ^ What does that mean

There will be less software writers and more architects

- Software engineers are free to think at even higher levels of abstraction
- Infrastructure concepts like networking, hosting, CI/CD will become more important
    - Tools like Dockploy and Coolify make infrastructure easy
    - Shift more towards on-prem in the future?
